AllviA LearnFit | 학급 관리 컨셉 목업 v0.1

[실행 방법]
1. 이 폴더를 VS Code에서 엽니다.
2. index.html을 브라우저에서 직접 열거나, VS Code의 Live Server 확장으로 실행합니다.
3. 외부 라이브러리를 사용하지 않아 인터넷 연결 없이도 동작합니다.

[구현 범위]
- 학급 종합 현황
- 수업 리포트
- 과제 리포트
- 학생 분석
- 인사이트·후속 조치

[인터랙션]
- 좌측 메뉴 전환
- 기간 필터 전환
- 수업/과제 선택
- 학생 상세 드로어
- 학생 분석 대상 변경
- 데이터 기준 모달
- 일부 후속 조치 버튼 토스트

[기획 기준]
- AllviA_LearnFit_학급관리_기획초안_v0.1_260917.xlsx
- LumiTeach 수업 리포트 / 과제 리포트 벤치마킹
- LearnFit 차별화 가설: 누적 학급 현황, 수업 과정 복기, 행태 분석, 인사이트 → 후속 조치 연결

[주의]
